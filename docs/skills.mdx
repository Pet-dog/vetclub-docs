# Skills catalog

This public snapshot lists two distinct sets:

- 25 baseline capabilities available in the default task profile;
- 52 optional Vercel skills selected only for tasks that need them.

Publishing a skill here does not enable it automatically. The baseline remains
limited to 25 skills; optional skills are connected through task-specific
selection.

## What is deliberately absent

The catalog does not publish skill bodies, local paths, installation state,
source coordinates, repository identities, hashes, private instructions, or
unlisted task-specific packages.
