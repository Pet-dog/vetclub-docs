# VetClub Engineering

This is a small Docs7 Free canary for VetClub's public technical material.
It tests whether one source can serve readable documentation to people and
clean Markdown to agents without changing the existing preview workflow.

## Canary scope

The first release contains one public surface: the catalog of 25 baseline
agent skills. Each catalog entry exposes only a stable name and a short public
summary.

## Publication boundary

This site is built from a dedicated public repository. It has no connection to
private VetClub repositories and contains no source code, credentials,
customer or patient data, internal runbooks, or private knowledge material.

## Versioning

Documentation changes arrive through ordinary GitHub pull requests. The
existing GitHub and Vercel preview workflow remains the review path; Docs7 Pro
features are not part of this canary.
